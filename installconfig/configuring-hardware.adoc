= 設定 StorageGRID 應用裝置硬體
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
為應用裝置加電後、您可以設定 StorageGRID 將使用的網路連線。



== 必要的硬體組態



=== 網路連線

您必須設定並驗證所有應用裝置所需的網路連線：

* link:../installconfig/accessing-storagegrid-appliance-installer.html["存取應用裝置安裝程式"]
* link:../installconfig/configuring-network-links.html["設定網路連結"]
* link:../installconfig/verifying-port-level-network-connections.html["驗證連接埠層級的網路連線"]




=== BMC 介面

如果您要安裝以下任何一種應用裝置，則必須link:../installconfig/configuring-bmc-interface.html["設定基板管理控制器 (BMC) 介面"]：

* SG100
* SG110
* SG120
* SG1000
* SG1100
* SG1200
* SGF6024.
* SGF6112
* SGF6212
* SG6060
* SG6160
* SG6260


您可以使用 BMC 介面設定設備的 SNMP 和其他底層設定。它還允許您排查硬體安裝故障、確定設備的電源狀態以及控制設備上的標識 LED。

若要深入瞭解 BMC 可使用的功能，請參閱link:../commonhardware/use-bmc.html["使用 BMC 介面"]。



== 選用硬體組態



=== 系統管理程式SANtricity

如果您擁有以下應用裝置之一，即可link:../installconfig/accessing-and-configuring-santricity-system-manager.html["設定 SANtricity System Manager"]：

* SG5712
* SG5760
* SG5812
* SG5860
* SGF6024.
* SG6060
* SG6160
* SG6260


SANtricity System Manager 軟體可讓您執行以下操作：

* 監控應用裝置的系統效能資料、硬體元件狀態和支援功能
* 管理磁碟機安全性金鑰、SNMP 和 syslog 警示、以及用於存取 SANtricity System Manager 的管理員密碼
* 設定對 E 系列 AutoSupport 的存取




=== 啟用節點或磁碟機加密

您可以 link:../installconfig/optional-enabling-node-encryption.html["啟用節點或磁碟機加密"] 採取措施保護應用裝置中的磁碟機和磁碟。



=== 更改 RAID 模式

您可以 link:../installconfig/optional-changing-raid-mode.html["變更儲存設備的 RAID 模式"] 以滿足您的儲存與還原需求。

以下應用裝置支援變更 RAID 模式：

* SG5760
* SG5860
* SGF6024.
* SG6060
* SG6160
* SG6260




=== 重新對應網路連接埠

您可以 link:../installconfig/optional-remapping-network-ports-for-appliance.html["重新映射應用裝置上的網路連接埠"] 優化網路連線。
