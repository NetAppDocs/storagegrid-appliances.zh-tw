= 維護 SG6200 應用裝置
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可能需要對設備進行維護程序。本節包含維護 SG6200 設備的特定程序。

本節中的程序假設應用裝置已部署為StorageGRID 位於整個系統的儲存節點。

* 維護組態程序 * 是使用 Appliance Installer 、 Grid Manager 或 BMC 介面來執行。這些程序包括：

* link:turning-sg6200-identify-led-on-and-off.html["開啟和關閉產品識別 LED"]
* link:locating-sg6200-in-data-center.html["在資料中心找到應用裝置"]
* link:power-sg6200-off-on.html["關閉產品電源"]
* link:changing-link-configuration-of-sg6200-appliance.html["變更應用裝置的連結組態"]


*硬體維護程序* 需要對特定的 SGF6212 或 SG6260 元件進行實體操作。



== 磁碟機韌體升級

每次應用裝置重新開機時，系統會自動檢查 SG6260 中磁碟機的韌體。必要時、韌體會自動升級至目前 StorageGRID 版本所需的版本。通常、韌體升級會在 StorageGRID 軟體升級期間進行。現有 StorageGRID 版本所需的任何磁碟機韌體升級都會包含在 Hotfix 中。請遵循每個 Hotfix 隨附的指示、確保升級套用至所有可從中受益的磁碟機。

此外，SG6260 中的磁碟機可以透過 SANtricity 使用 link:upgrading-drive-firmware-using-santricity-system-manager-online.html["SANtricity System Manager 線上版"] 或 link:upgrading-drive-firmware-using-santricity-system-manager-offline.html["SANtricity System Manager 離線"] 程序進行更新。


NOTE: 維護 SGF6212 設備不需要 SANtricity System Manager。
