[[sg120-and-sg1200-services-appliances]]
== SG120 和 SG1200 服務應用裝置

全新的 StorageGRID SG120 和 SG1200 服務應用裝置是硬體的升級換代產品，可提供更佳的管理和負載平衡效能。請參閱 link:./installconfig/hardware-description-sg120-and-1200.html["SG120 與 SG1200 服務應用裝置：概述"] 以瞭解更多資訊。



[[sgf6212-appliance]]
== SGF6212 應用裝置

新款 StorageGRID SGF6212 儲存設備採用緊湊型設計，將運算控制器和儲存控制器整合於 1U 機箱內。該設備支援 12 個 SSD NVMe 磁碟機，可組成 RAID 陣列，提供彈性物件儲存。請參閱link:installconfig/hardware-description-sg6200.html["SGF6212 應用裝置：概述"]以深入瞭解。



[[sg6260-appliance]]
== SG6260 應用裝置

新款 StorageGRID SG6260 設備包含一個運算控制器和一個儲存控制器機架，該機架包含兩個儲存控制器和 60 個硬碟，以及兩個用於快取的 NVMe SSD 硬碟。可選配 60 個硬碟的擴充機架至 SG6260。詳情請參閱link:./installconfig/hardware-description-sg6200.html["SGF6200 應用裝置：概述"]。



[[client-network-can-be-configured-without-an-ip-address]]
== 用戶端網路無需 IP 位址即可配置

現在您可以啟用客戶端網路而無需指定 IP 位址。這允許客戶端網路在StorageGRID中配置 VLAN 接口，而無需為接口本身提供額外的 IP 位址。請參閱link:.//installconfig/setting-ip-configuration.html["設定StorageGRID 靜態IP位址"] 。



[[version-numbers-for-storagegrid-software-and-appliance-installer-aligned]]
== StorageGRID軟體和 Appliance Installer 的版本號碼已對齊

對於 StorgeGRID 版本 12.0， StorageGRID Appliance Installer 的版本號碼與StorageGRID軟體的版本相符。使用者不再需要弄清楚哪些版本可以一起使用。請參閱link:./installconfig/verifying-and-upgrading-storagegrid-appliance-installer-version.html["驗StorageGRID 證並升級版本的應用程式"] 。
